# Tipos de letra

Auto-alojados. Nenhuma página faz pedidos a servidores de terceiros.

Todos os quatro estão sob a **SIL Open Font License 1.1**, que permite uso
comercial, modificação e redistribuição desde que a licença acompanhe os
ficheiros. É por isso que este ficheiro existe.

| Ficheiro | Família | Autoria | Onde é usado |
|---|---|---|---|
| `archivo-latin.woff2` | Archivo (variável 400-800) | Omnibus-Type | `index.html` |
| `petrona-latin.woff2` | Petrona (variável 400-700) | Omnibus-Type | `demo-alojamento.html` |
| `publicsans-latin.woff2` | Public Sans (variável 400-800) | USWDS / Dan Williams | `demo-clinica.html` |
| `chivo-latin.woff2` | Chivo (variável 400-900) | Omnibus-Type | `demo-loja.html` |

Subconjunto **latin** apenas. Cobre `U+0000-00FF`, o que inclui todos os
diacríticos do português: ã ç õ á é í ó ú â ê ô à. Não cobre polaco, checo
nem turco — se algum dia for preciso, acrescenta-se o subconjunto `latin-ext`.

Texto integral da licença: <https://openfontlicense.org/>

## Porquê estes

Três palavras do `PRODUCT.md`: **oficinal, exacto, sem verniz**.

- **Archivo** é um grotesco desenhado a partir das grotescas americanas do
  século XIX usadas em impressão comercial: cartões, faturas, formulários.
  É literalmente tipografia de oficina. É a voz do Gabriel.
- **Petrona** é uma serifa de baixo contraste, robusta, sem ares de revista.
  Serve uma casa de xisto sem cair no romantismo de mercado de Natal.
- **Public Sans** é neutra e institucional. Numa clínica, a tipografia não
  deve competir com o formulário de marcação.
- **Chivo** aguenta o peso 900 sem se desfazer, que é o que uma marca de
  retalho precisa no cabeçalho.

Rejeitados por serem reflexo de dados de treino, conforme a lista do
`brand.md`: Inter, Space Grotesk, IBM Plex, Fraunces, Playfair, DM Sans,
Instrument Serif, Outfit, Syne.
